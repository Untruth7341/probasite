# Grikona

Учебный статический лендинг агентства недвижимости Grikona (Валенсия) в стиле
[matchowner.com](https://matchowner.com), но с собственной палитрой (песок,
тушь, золото, оранжевый акцент).

Сайт полностью статический: HTML + CSS + ванильный JavaScript, без сборки и
зависимостей.

- Демо: https://untruth7341.github.io/probasite/
- Страница для агентств: https://untruth7341.github.io/probasite/inmobiliarias.html

## Возможности

- Мультиязычность **ES / EN / ZH / RU** с переключателем в шапке; выбор
  сохраняется в `localStorage`.
- Анимации: появление по скроллу, счётчики, бегущая строка, свайп-колода
  объектов, аккордеоны, табы, «шагающий» маркер на roadmap.
- Чат поддержки (имитация ответа оператора).
- Адаптивная вёрстка.

## Структура

```
index.html            основной лендинг
inmobiliarias.html    страница для агентств
css/styles.css        стили
js/i18n.js            словари и логика перевода (ES/EN/ZH/RU)
js/main.js            анимации и интерактив
js/chat.js            чат поддержки
img/favicon.svg       иконка
docs/STATUS.md        журнал состояния проекта
```

## Как запустить

Просто открыть `index.html` в браузере.

Или поднять локальный сервер (чтобы корректно работали относительные пути):

```sh
python3 -m http.server
```

Затем открыть http://localhost:8000/

## Заметки

- Внешние ассеты (Google Fonts, Unsplash) подгружаются из интернета — офлайн
  сайт отобразится не полностью.
- Формы и чат — демонстрационные: данные никуда не отправляются.
- Контакты и юридические ссылки в футере — заглушки.
